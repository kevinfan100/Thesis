\chapter{System Identification of Magnetic Flux Generation Dynamics}

\section{Introduction}

This chapter develops the system-identification stage of the dissertation and converts open-loop calibration measurements into model information that can be used directly for flux-control design. The chapter follows the Hall-sensor-based hexapole modeling direction established in prior work, while reorganizing the identification path into a reusable and automation-ready workflow \cite{long2022hallsensor,meng2024piconewton}.

The technical emphasis is control-oriented model usability rather than fitting score alone. The target is to preserve coupling structure and control-relevant dynamic behavior from measured data, so that downstream design decisions in Chapter 4 can be explained and reproduced.

\section{Automated Open-Loop Calibration Workflow}

Open-loop calibration is executed using an automated processing chain implemented in the Openloop\_Cali package. The workflow consists of: sweep excitation and synchronized data logging, steady-state window detection, super-period frequency-domain conversion, dominant-component extraction, and fitting-stage data assembly.

For each excitation frequency, the dominant response component is used to construct amplitude-ratio and phase-lag data. THD and loop-shape diagnostics are retained as auxiliary indicators of nonlinearity, but the model-construction path remains focused on the dominant component used for control-oriented linearization at the tested operating condition.

This automation stage removes case-by-case manual preprocessing and creates a consistent data interface for comparing fitting strategies. As a result, identification outputs can be regenerated and traced under the same processing assumptions.

\section{Frequency-Response Construction and Key Dynamic Observations}

The calibration experiments produce six-output responses under each single-input excitation. Repeating this for all six inputs yields a six-by-six response structure that exposes coupling among channels and provides the data basis for model construction.

\subsection{Dominant-Component Extraction and Bias Handling}

Remanence-related bias and phase offset are visible in raw open-loop measurements. To obtain comparable response data, the identification process uses dominant-frequency extraction and phase-offset normalization before model fitting. This treatment does not assume globally linear actuator physics; it provides a control-usable local representation for the tested condition.

\subsection{Coupling, Hysteresis-Related Behavior, and Usable Bandwidth Clues}

The measured responses show three key characteristics: channel coupling, remanence/hysteresis-related effects, and frequency-dependent amplitude-ratio and phase-lag variation. These observations provide practical clues for model-design priorities, including low-frequency fidelity inside the intended control bandwidth and explicit retention of coupling behavior for multi-axis control design.

\section{Dynamic Modeling of Magnetic Flux Generation}

Based on the identified response data, this chapter adopts two complementary fitting paths to build a control-usable model structure.

\subsection{One-Curve Weighted Fitting for Channel-Wise Dynamics}

The first path fits each channel pair independently using a second-order model with low-frequency-priority weighting:
\begin{equation}
H_{ij}(s) = \frac{b_{ij}}{s^{2} + a_{1,ij}s + a_{2,ij}} .
\end{equation}
This path provides channel-level interpretability and serves as a transparent baseline for checking fitting behavior across all 36 channel pairs.

\subsection{Multi-Curve Weighted Fitting for Shared Dynamics and Coupling Structure}

The second path jointly fits all channel pairs and extracts shared dynamics with a coupling matrix:
\begin{equation}
\mathbf{H}(s) = \frac{A_{2}}{s^{2} + A_{1}s + A_{2}}\,\mathbf{B}.
\end{equation}
Here, $\mathbf{B}$ preserves relative coupling and gain distribution across channels, while the shared second-order dynamics provide a compact representation for controller design iteration.

\subsection{Final Identified Model for Control Development}

The model selected for downstream use is the shared-dynamics-plus-coupling representation, because it balances structural compactness and coupling fidelity for six-input six-output control design. The output of this chapter is therefore a continuous-time identified model and associated parameter set that can be directly consumed by the flux-control design workflow.

Discrete-time transformation and closed-loop synthesis are intentionally deferred to Chapter 4, where digital-control design choices are introduced in their proper context.

\section{Validation for Control Design Use}

Validation in this chapter is defined by control-development usefulness: whether the identified model reproduces measured amplitude-ratio and phase-lag behavior within the control-relevant frequency range and preserves coupling tendencies needed for multi-axis design decisions.

Simulation and experiment are used together under the same identification assumptions to check consistency between predicted and measured trends. The outcome of this validation is a justified model interface for Chapter 4, not a standalone end-performance claim.

\section{Summary}

This chapter established an automated and traceable identification workflow from open-loop calibration to model extraction. The resulting model captures coupling and dominant dynamics in the control-relevant range and provides the model basis for flux-control design in Chapter 4.

At the dissertation level, this chapter completes the first technical stage of the automation objective: turning measured actuator behavior into reusable and controller-ready model artifacts.
